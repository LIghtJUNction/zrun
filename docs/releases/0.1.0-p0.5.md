# zrun 0.1.0-p0.5

P0 预览版，提供 Rust 异步库、Linux 命令服务和原生 `.zrun` 脚本。

- 使用 `async 名称 -- 命令` 提交行内 shell 命令，用 `await 名称` 等待结果。命令由配置的 shell 处理引号、管道和重定向。
- Unix socket 支持有界连接复用。本地脚本可以分组提交连续的任务，远程脚本保留独立的任务结果。
- `ZRUN_BATCH_WINDOW=2` 至 `8` 可让远程 JSONL 批处理跨批次并行，结果按输入顺序输出。
- 增加单调时钟绝对截止时间及异步超时接口。定时器仅在最早截止时间改变时通知驱动。
- 用户可在 Unix 的 zrun/shell 配置文件指定登录 shell 后端，见[命令服务文档](../agent-shell.md)。

Linux CLI 可从本次发布下载，也可运行 `cargo install zrun-cli --version '=0.1.0-p0.5' --locked`。需要 Rust 1.100 或更高版本。插件开发可使用 `zrun-plugin-api`。

完整 shell 兼容、长期稳定性、跨平台和 Tokio 多维性能仍处于验收阶段。
