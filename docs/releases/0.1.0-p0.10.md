# zrun 0.1.0-p0.10

P0 预览版。Linux 上经 Unix socket 执行远程批处理时，可用 `zrun batch --ready` 优先输出已完成的批次，并立即补发请求。每行保留原始输入的 `index`，单批内保持输入顺序。省略 `--ready` 时，远程模式继续按输入顺序输出。

使用四 worker、请求窗口为 2 的本地 broker，交替运行 12 对快慢混合批处理。每次输入 96 条命令，其中首条等待 150 ms。首条结果的中位数由 154.1 ms 降到 10.8 ms，整批中位数由 172.2 ms 降到 154.1 ms。每条结果的下标、退出码和内容均已核对。

需要 Rust 1.100 或更高。安装命令为 `cargo install zrun-cli --version '=0.1.0-p0.10' --locked`。
