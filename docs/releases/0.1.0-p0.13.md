# zrun 0.1.0-p0.13

这个 P0 预览版更新了 Linux 原生交互 shell 的目录导航和路径编辑。

- 在提示符输入 `..` 可返回上一级。直接输入目录名或粘贴完整目录路径可进入该目录，支持中文、空格和结尾的斜杠。切换后可用 `cd -` 回到原目录。同名别名、内建命令和 `PATH` 中的可执行程序优先执行。脚本继续使用显式 `cd`。
- Ctrl-W 每次删除光标左侧的一个路径分量。例如，在 `cd src/native/editor/` 末尾按一次会留下 `cd src/native/`，再按一次留下 `cd src/`。光标右侧的文字会保留。

Linux x86_64 可执行文件名为 `zrun-0.1.0-p0.13-linux-x86_64`。同一发行页的 `SHA256SUMS.txt` 提供文件校验值，`SOURCE_COMMIT.txt` 记录构建所用的 Git 提交。也可使用 Rust 1.100 按此版本的锁文件构建：

```sh
cargo build --release --locked -p zrun-cli
```
