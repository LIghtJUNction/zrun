# zrun 0.1.0-p0.7

P0 预览版，提供 Rust 异步运行时、Linux 命令服务和原生 `.zrun` 脚本。

- Rust 库新增 `Pool::new_with_io` 和 `Pool::with_max_tasks_and_io`。一个执行 worker 同时推进 I/O 和定时器。Linux CLI 可用 `ZRUN_WORKERS=4 ZRUN_IO_DRIVER=worker` 启用，多 worker 的默认模式继续使用独立 I/O 线程。
- 远程 `zrun batch` 和原生脚本在提交第一条命令前校验全部请求大小。预编码缓存上限为 2 MiB，单条 MCP 消息编码上限为 256 KiB。
- 批处理输入复用行缓冲，并在执行前读取、校验完整输入。

四 worker、单连接 64 B 回显相对先前的专用 reactor，吞吐提高 30.5%，往返 P99 下降 34.8%。在 16 worker、64 连接的专项对照中，zrun 的吞吐和 P99 领先 Tokio，但服务端 CPU 开销仍约为 Tokio 的两倍。完整 shell 兼容、跨平台、长期稳定性和 Tokio 多维性能继续验收。

Linux CLI 可下载发行二进制，或运行 `cargo install zrun-cli --version '=0.1.0-p0.7' --locked`。需要 Rust 1.100 或更高。
