# zrun 0.1.0-p0.11

P0 预览版。异步 I/O 新增 `zrun::io::Stream::read_exact`。一次调用可跨多个就绪事件填满缓冲区，复用同一就绪注册。提前结束时返回 `UnexpectedEof`。取消调用会移除等待注册，已读字节仍保留在缓冲区，调用方需跟踪协议的读入进度。

CLI 包含 Unix socket 批处理、可选 Valkey 二级结果缓存，以及 stdio 和 Streamable HTTP MCP 服务。需要 Rust 1.100 或更高。安装命令为 `cargo install zrun-cli --version '=0.1.0-p0.11' --locked`。
