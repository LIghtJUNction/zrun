# zrun 0.1.0-p0.1

首个 P0 预览发行提供独立单线程 Rust Future 执行器、有界任务接收、JoinHandle、显式取消、定时器及关闭路径。核心运行时只依赖标准库和同仓模块；Tokio 仅用于独立比较器。

## 已有证据

实现提交为 `12e6421ddfc898658ab59f97e922979e85d8b597`。Linux 本地记录包含 43 项常规测试、显式百万任务测试、35 项核心 Miri 检查、400 个比较进程样本及 120 秒持续运行检查；完整口径见 [P0 验收记录](https://github.com/LIghtJUNction/zrun/blob/main/docs/measurements/p0-linux-20261123.md)。本次发行保留原始性能结果，没有修改运行时实现。

首次测量尚未达到与 Tokio 比较的性能目标。多线程调度、I/O reactor、TCP、Loom 和 24 小时稳定性属于后续阶段。本版本因此标记为预览发行。

## 发布门禁与制品

正式发布工作流复用同一份源码门禁，在 Linux、Windows 和 macOS 上运行格式、workspace 测试、Clippy、Python 证据自测、运行时依赖边界及比较器协议检查。只有这些作业全部成功才创建 GitHub Release。

发行提供完整源码归档、`SOURCE_COMMIT.txt` 和 `SHA256SUMS.txt`。归档对应通过门禁的同一个完整提交。GitHub 工作流的实际结论以该次运行记录为准；源码门禁不替代长时间性能与稳定性验收。

## 使用

需要 Rust 1.100.0。下载源码后执行 `cargo run --locked --example p0`。Project Z 内部跨仓消费者使用公开默认分支 Git URL，并在 Cargo.lock 中记录实际提交；本轮没有把现有网络或进程运行时替换成 P0。
