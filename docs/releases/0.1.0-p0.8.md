# zrun 0.1.0-p0.8

P0 预览版。Linux 命令服务新增默认关闭的 Valkey 二级结果缓存。

- 设置 `ZRUN_VALKEY_SOCKET`、`ZRUN_VALKEY_DOMAIN`、`ZRUN_VALKEY_TOOL_REVISION` 可启用。只有授权通过、显式声明复用且 TTL 大于零的命令才会访问二级缓存。
- zrun 继续在单个 broker 内合并在途请求。可复用结果会以 `SET … PX` 写入 Valkey，在 broker 退出后仍可由同一信任域的新进程读取。
- 缓存键纳入工具版本和继承环境。Valkey 无法访问或无响应时，broker 回退到本地执行并短暂退避。空闲连接按命令 worker 复用。
- Linux 同机测试中，500 个不同复用键在 broker 重启后全部命中，没有启动子进程。完成耗时中位数为 39.9 ms，对照关闭 Valkey 时为 315.5 ms。结果仅覆盖该测试负载。

安装：`cargo install zrun-cli --version '=0.1.0-p0.8' --locked`。需要 Rust 1.100 或更高。
