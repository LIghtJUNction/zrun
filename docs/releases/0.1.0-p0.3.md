# zrun 0.1.0-p0.3

这是 zrun 的 P0 预览版本。

- 普通 `.zrun` 文件使用配置的 shell，保留位置参数和退出行为。原生模式由首行 `# zrun:1` 启用，支持命名的 `async` 任务和按名字 `await`。
- Linux 原生脚本可通过 `ZRUN_SOCKET` 接入同一个执行服务。脚本、CLI 和 MCP 共用队列、授权和显式复用缓存。相对工作目录从脚本进程解析。
- 多线程 Pool 将任务登记分片，保留全局容量检查、取消和关闭语义。

19 项 CLI 回归已经覆盖本地并发、Unix socket 跨进程缓存、MCP 和授权。Linux 压力测试在最多 64 个客户端同时运行的条件下启动 512 个独立脚本，共提交 4,096 个声明相同复用键的任务。全部请求得到预期输出，服务实际执行 1 次。复用结果以相同输入版本和有效期为前提。
