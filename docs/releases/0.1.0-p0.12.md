# zrun 0.1.0-p0.12

本次 P0 预览更新了 Linux 原生交互 shell 和本地 MCP 命令服务。运行 `zrun` 进入交互会话，`zrun -c '…'` 使用同一套原生语法。Shell 在会话中保存当前目录、变量和命名任务，可以在一行用 `async` 启动命令，随后用 `await` 取回结果。

- **终端编辑。** 单个明确候选可用 Tab 补全。多个候选显示在当前输入行下方，可用 Tab 和方向键切换、继续键入筛选，或用 Esc 收起。Git 子命令、选项和普通工作树中的本地分支均有候选。例如，`git sw<Tab>` 补成 `git switch `。选择带空格的路径时保留参数边界。确认输入后，编辑器收起菜单并交还终端给前台程序。
- **交互配置。** `zrun --rc-path` 显示原生启动文件的位置。`zrunrc` 可定义变量和简单命令别名，`ZRUN_NO_RC=1` 可临时跳过。已有的 Zsh 配置、插件和 ZLE 控件由 `zrun --zsh` 显式启动本机 Zsh 加载。
- **AI 客户端。** `zrun ai config` 输出客户端配置，`zrun ai connect --stdio` 接受标准 MCP 请求。`zrun ai run` 执行命令，`zrun ai compact` 可从管道读取已有输出。MCP 工具 `shell_run_compact` 分别预览标准输出和标准错误，合并连续重复行并保留退出码。保留期内，`output_read` 可用私有句柄分段读取同一次执行捕获的原始字节。原有 `shell_run` 和 `shell_batch` 继续返回完整的已捕获结果。

Linux x86_64 发行资产名为 `zrun-0.1.0-p0.12-linux-x86_64`，其校验值列于同一发行页的 `SHA256SUMS.txt`。源码构建需要 Rust 1.100 或更新版本。在此 tag 的源码目录运行 `cargo build --release --locked -p zrun-cli`，Linux 可执行文件位于 `target/release/zrun`。运行时库及其工作区组件使用相同的 P0 预览版本号。
