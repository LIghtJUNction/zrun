# zrun 0.1.0-p0.14

这个 P0 预览版更新了 Linux 原生交互 shell 的命令补全。

- zrun 可读取系统安装的 Bash 补全定义。输入 `systemctl status` 或 `systemctl --user status` 后按 Tab，候选来自对应的 systemd 管理器。Fish 无需安装。
- 外部命令没有补全定义时，无法判断类型的参数留空。以 `./` 等路径前缀输入的参数、重定向和 `cd` 仍可补全路径。
- 本版包含远程交互会话的设计草案。会话恢复和本地预测回显尚未实现。

Linux x86_64 二进制、源码归档和校验值与 GitHub 预览版一起发布。`SOURCE_COMMIT.txt` 记录构建对应的提交。
