# zrun 0.1.0-p0.9

P0 预览版，包含 Linux MCP 连接复用和可选缓存写入改进。

- MCP Streamable HTTP 的 TCP 客户端可以显式请求 `Connection: keep-alive`。每条请求仍独立校验 Bearer 令牌，每条连接最多处理 64 次顺序请求。
- Linux 回环实测中，512 条顺序工具列表请求使用 8 条连接，逐条关闭则使用 512 条。12 对测试的耗时中位数分别为 65.5 ms 和 83.7 ms。此场景不包含命令执行时间。
- Valkey 写入使用分段缓冲区发送 RESP 大结果，避免为传输再复制一份完整的编码输出。Valkey 二级缓存继续默认关闭。

需要 Rust 1.100 或更高。安装命令为 `cargo install zrun-cli --version '=0.1.0-p0.9' --locked`。
