# zrun 0.1.0-p0.4

这是 zrun 的 P0 预览版本，包含 Rust 异步库和 Linux 命令执行服务。

- 原生 `.zrun` 脚本支持 shebang、位置参数、`await 名称1 名称2` 和 `await *`。普通脚本仍交给配置的 shell 运行。
- Unix socket 会把位置参数原样传给命令。zguard 检查参数，复用键也包含参数。zplugin 准入接口 v2 支持检查位置参数，v1 仍支持无参数任务。
- `Pool` 和 `PoolSpawner` 支持分批提交。命令服务以批量接口启动并行处理任务，MCP 的 `shell_batch` 分组入队，逐条授权。缓存命中直接交付结果。
- 修复了登录 shell 通过指向 zrun 的 Unix 可执行文件别名反复启动的问题。

百万任务对照中，使用批量提交且每个任务自唤醒 16 次时，1、2 worker 的完成耗时比 Tokio 低约 31%、14%。16 worker 仍明显落后。跨平台、长期稳定性和同时超过 Tokio 多项性能的整体门槛仍待验收。
