# zrun 0.1.0-p0.6

P0 预览版，提供 Rust 异步库、Linux 命令服务和原生 `.zrun` 脚本。

- `await --ready` 等待所有待收任务，并优先交付已可用的结果。具名 `await` 与 `await *` 仍可指定交付顺序。
- 每个原生任务结果在交付时刷新 stdout，包括无换行的输出。本地 `zrun batch` 逐行交付完成的 JSONL 结果。
- 普通 `.zrun` 脚本可使用 shebang 指定解释器。`zrun -- -FILE.zrun` 支持以连字符开头的文件名。
- 对照基准新增批量提交和并发外部唤醒场景，验证任务结果并记录观察到的重叠次数。

Linux CLI 可从本次发布下载，或用 `cargo install zrun-cli --version '=0.1.0-p0.6' --locked` 安装。需要 Rust 1.100 或更高版本。

完整 shell 兼容、长期稳定性、跨平台与 Tokio 多维性能仍处于验收阶段。
